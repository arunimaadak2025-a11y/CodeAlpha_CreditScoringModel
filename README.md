# Credit Scoring Model

## Project Overview

This project predicts a customer's creditworthiness using Machine Learning. The model analyzes financial and credit-related information such as loan amount, age, employment duration, savings, and credit history to determine whether a customer is a low-risk or high-risk borrower.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Random Forest Classifier

## Features

* Data Preprocessing
* Credit Risk Prediction
* Accuracy Evaluation
* Classification Report
* Confusion Matrix
* Customer Creditworthiness Assessment

## Result

* Model Accuracy: 77.5%
